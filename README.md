## Introduction
This is a tool for creating lightweight, modular neural networks.

Neural networks, and related components, are packaged into "ninos". A "neural nino" has the following properties:
- name
- input size (the expected dimensions of the input matrix)
- output size
- number of layers
- parameter size<br>
Ninos can also be calls to custom C functions, which we call "functional ninos".
