## Notation
### Urgency
This describes how urgent the task is to complete, based off the functionality the task provides, and how much it would improve the community's experience. The table below gives a description of each level.

| | Urgency Level | Meaning |
| - | - | :-- |
| :bangbang: | Critical | The project is not functional without this task being completed. |
| :warning: | Important | The project is inconvenient and barely useable without this task being completed. |
| :chart_with_upwards_trend: | Moderate | The project would greatly benefit from this task being completed. |
| :wrench: | Minor | The project would somewhat benefit from this being completed. |

### Stage
This describes how far along the task is towards completion. The table below gives a description of each stage.
| | Stage | Meaning |
| - | - | :-- |
| :open_file_folder: | Not started | This task has been acknowledged, but no work has been done on it. |
| :memo: | In progress | This task has some partial completion. If a task stays in this stage for too long, consider breaking it up into smaller tasks that are each tracked. |
| :test_tube: | Under testing | This task has an initial completion, and has passed the relevant test suites, but is still an experimental feature for the community. |
| :white_check_mark: | Completed | This task is completed and merged into the main branch. |
